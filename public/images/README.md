# Image Assets

This directory contains placeholder images for the Keltech website.

## hero.jpg
A placeholder image for the hero section. The component will automatically fall back to a Pexels image if this file is not available.

## Recommended Images:
- hero.jpg: Modern technology/engineering workspace (1200x900px minimum)
- project-1.jpg: Automotive/fleet management visualization
- project-2.jpg: Healthcare data/medical technology
- project-3.jpg: Banking/payment processing interface

All images will automatically load from Pexels CDN if local files are not found.
